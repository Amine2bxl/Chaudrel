# Chaudrel — kit de marque

Séparé du code du site (`src/`). Le site n'en reprend que des copies : `public/logo-*.svg`,
`public/favicon.svg`, les icônes et `public/og-image.jpg`.

## Provenance

- `source/logo-client.webp` — logo fourni par Chaudrel (novembre 2026), fichier matriciel 1254 px.
- `logo/*.svg` — vectorisation de ce fichier (potrace, échantillonnage ×4). La porte bronze est
  un tracé séparé, redessiné à partir de ses quatre coins mesurés. Couleurs relevées sur le
  fichier : crème `#FCF4EC`, noir chaud `#24221E`, bronze `#AE8A56`.
- `public/favicon*`, `public/icon-*`, `public/apple-touch-icon.png`, `public/og-image.jpg`,
  `public/chaudrel-logo.{jpg,webp}` — rendus de ces SVG (Chromium), aucune image générée par IA.

⚠️ Une vectorisation reste une approximation : pour l'impression grand format, demander au
graphiste d'origine le fichier vectoriel natif s'il existe.

La suite du kit (carte de visite, t-shirts, fiche Google Business, documents) arrive dans une
PR dédiée.
