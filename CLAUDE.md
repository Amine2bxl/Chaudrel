# Chaudrel — site

Site vitrine + devis de Chaudrel Rénovation (Schaerbeek). React 18, Vite 5, Tailwind 3, pré-rendu statique, Vercel.

## Commandes
- `npm install`
- `npm run dev` — http://localhost:5173
- `npm run build` — vite build + pré-rendu + sitemap
- `npm run preview`

## Règles
- Contenu dans `src/data/*`. Aucun chiffre, avis, délai ou prix non validé (voir `docs/VERIFICATION.md`).
- Produit : `PRODUCT.md`. Kit de marque : `brand/` (séparé du site).
